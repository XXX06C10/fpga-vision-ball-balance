# FPGA + D36A + MS42CG 单电机接线说明

本方案使用 HX1P35A V1.0 开发板、D36A 驱动器第一路 CN1（Motor A）、一个 MS42CG 编码器步进电机。

所有 FPGA 针号均指板上左侧、靠网口的 **J1 40 针扩展插座**，不是 FPGA 芯片的 BGA 管脚号。接线和修改拨码前关闭 FPGA 和 D36A 电源。

## 1. 整体连接

```text
外接 12V 电源 ── Vin+/Vin− ── D36A ── CN1 四芯动力线 ── 电机
                              ↑                         │
                     ST1、DIR1、EN1、GND                 │
                              │                         │
电脑 USB ─────────────────── FPGA ←─ 六芯编码器线 ── 电机尾部编码器
```

## 2. 电机动力线 → D36A

使用配套四芯动力线，将电机四针动力接口接到 D36A 的 **CN1 / Motor A**。

| 电机相线 | D36A 第一路电机接口 |
|---|---|
| A+ | A+ |
| A− | A− |
| B+ | B+ |
| B− | B− |

按实际丝印和绕组对应，不凭线色猜。原配线若已经正确插在 CN1 且未改线，可保留。CN2 / Motor B 暂时空着。

## 3. FPGA → D36A 控制线

| FPGA J1 扩展插座针号 | 板卡信号 / 芯片管脚 | D36A 控制接口 |
|---|---|---|
| 1 | GPIOA_0 / C18 | ST1（STEP1） |
| 2 | GPIOA_1 / D15 | DIR1 |
| 3 | GPIOA_2 / E12 | EN1 |
| 12 | GND | GND |

ST1 每个上升沿产生一步（细分设置会影响一步角度）；DIR1 高低电平选择方向；EN1 高电平使能、低电平休眠。

按用户提供的 D36A 官方标注图方向（拨码在右上，电机插座在下方，控制插座在风扇左侧），控制插座布局如下：

```text
外侧列        靠风扇列
 ADC             5V      ← 不接
 EN2             EN1     ← FPGA 第3针
 DIR2            DIR1    ← FPGA 第2针
 ST2             ST1     ← FPGA 第1针
 GND             GND     ← FPGA 第12针
```

实物旋转后应按信号名对应，不能照搬图中的左右方向。D36A 的 5V、ADC、ST2、DIR2、EN2 暂时不接。

## 4. 电机编码器 → FPGA

按电机手册照片的观察方向，六针编码器插座从左到右为 **GND、Z、PWM、B、A、VCC**。插头翻转或观察方向改变后，左右顺序也会变化，应核对插座标注；不要凭线色猜。

| 编码器接口 | FPGA J1 扩展插座针号 | 板卡信号 / 芯片管脚 |
|---|---|---|
| GND | 30 | GND |
| Z | 7 | GPIOA_6 / F14 |
| PWM | 6 | GPIOA_5 / F13 |
| B | 5 | GPIOA_4 / E17 |
| A | 4 | GPIOA_3 / E16 |
| VCC | 29 | 3.3V |

编码器使用 3.3V 供电。编码器 A/B 是反馈输出，与电机动力线 A+/A−/B+/B− 不同。编码器 PWM 是角度反馈输出，不接 D36A ST1。

## 5. 电源

| 电源 | 接口 |
|---|---|
| 外接 12V 正极 | D36A 电源输入 Vin+ |
| 外接 12V 负极 | D36A 电源输入 Vin− |
| 电脑 USB | FPGA 原来的 USB 接口 |

D36A 的电源输入与另一组并联输出蓝色端子按实物丝印区分。并联输出暂时不接。风扇原有供电插头保持连接。

FPGA 第12针接驱动器 GND、第30针接编码器 GND，使三者共地。不要把 12V 或 D36A 的 5V 接到 FPGA GPIO。

## 6. FPGA J1 针号定位

按此前用户的 FPGA 近照方向（网口在上、板上文字正向），左侧长插座的第1针在最下端、靠电路板内侧一列，旁边有“1”标记。以实物标记为准。

```text
外侧（板边）     内侧（电路板）
   8                 7
   6                 5
   4                 3
   2                 1
       插座最下端
```

第12针在外侧列，从第2针起向上数第6根；相邻第11针是5V。第29针为3.3V，第30针为GND。不要把原理图的纸面方向直接当成实物方向。

## 7. 测试前约定

- 本文的 GPIO 分配是本项目选定方案，FPGA 程序和引脚约束必须使用相同分配；接好线本身不会使电机转动。
- 板载电脑串口使用 FPGA 芯片 H1（TX）和 J1（RX），与本方案的 GPIO 扩展插座 J1 是不同概念。
- 初次试验建议采用按键触发、低速、小角度、有限脉冲数的开环测试，再验证编码器，最后做闭环。
- 细分拨码必须与程序的每圈脉冲数一致。D36A 手册中，16细分对应拨码1/2/3均断开（非ON）；1.8°电机在16细分下为3200脉冲/圈。
- 电流档要结合电机额定电流与负载选择；空载验证可从小电流档开始。D36A 手册中拨码4/5/6均ON对应0.55A。小电流可能无法驱动现有机械负载。
